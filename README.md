# Traffic-Sign-Detection

Traffic Sign Detection using multiple datasets to determine the best base dataset for training models on different size and no of signs. This repository contains the code and report for the final model. 

### Key Notes
- **Model Saving**: The final model couldn't be saved properly on Google Colab, resulting in loss of training progress when reloaded.
- For detailed information, please refer to the full [report](Report.pdf).

### Repository Contents
- **Code**: Implementation of traffic sign detection models using CNNs.
- **Report**: Comprehensive documentation of methodologies, datasets, results, and discussions.

### Setup and Usage
1. Clone the repository.
2. Install dependencies.
3. Update dataset paths in the notebook as required.
4. Run the code using Jupyter Notebook or Google Colab.

### Additional Information
- Datasets used include German, Indian, and Traffic Signs datasets. Refer to the report for dataset details and performance comparisons.
- The model achieves the best accuracy on the German dataset with promising generalization potential across regions.

For further details, refer to the full report.
